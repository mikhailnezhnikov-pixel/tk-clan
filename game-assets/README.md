# Hamster King — каноническая библиотека игровых изображений

Источник библиотеки — HAR с `app.hamsterking.games`, предоставленный владельцем сайта 17.09.2026.

## Что включено
- 1 144 уникальных пути с `cdn-prod-art.hwgame.cloud`
- 73 уникальных пути с `cdn-prod-front-dist.hwgame.cloud`
- Итого: 1 217 уникальных официальных игровых ассетов

## Основные категории art-CDN
- `hamsters/` — хомяки и персонажи
- `hamsteresses/` — женские персонажи
- `items/` — предметы, шары, расходники, квестовые предметы
- `shop_lots/` — карточки и изображения предложений магазина
- `clans/` — клановые ассеты
- `factions/` — фракции
- `currencies/` — валюты
- `classes/` — классы
- `battle_passes/` — боевые пропуска
- `leaderboards/` — рейтинги
- `quests/` — квесты
- `bonuses/` — бонусные механики
- `special_events/` — ивенты
- `bosses/` — боссы
- `pvp_modes/` — PVP
- `skills/` — навыки

## UI-CDN
`cdn-prod-front-dist.hwgame.cloud/assets/images/` содержит интерфейс игры: фоны, меню, UI-иконки, заглушки и т.п.

## Использование
`catalog.js` содержит сжатый индекс всех 1 217 путей и возвращает:

```js
const catalog = await window.TK_GAME_ASSET_CATALOG();
```

Поля результата:
- `artBase`
- `uiBase`
- `art[]`
- `ui[]`
- `total`

Для URL изображения:

```js
const url = catalog.artBase + path;
```

или

```js
const url = catalog.uiBase + path;
```

## Правило для сайта
Если нужный игровой объект есть в этой библиотеке, использовать оригинальный игровой ассет вместо AI/стокового изображения. При неоднозначности сопоставления показать пользователю 1–3 кандидата и запросить подтверждение.

Важно: наличие пути в каталоге означает, что он был получен непосредственно из сетевого трафика/JSON игры. Это не означает, что каждый файл уже скопирован физически в репозиторий сайта.
