# HK / Top King — START HERE IN A NEW CHAT

## Обязательное правило

Не восстанавливать существующую механику HK по памяти, описанию в чате, скриншотам или roadmap.

Перед любым изменением userscript сначала открыть:

1. `baseline/topking/BASELINE.json`
2. `baseline/topking/HamsterKingMobile.current.user.js`
3. `baseline/topking/README.md`
4. `docs/HK_MASTER_ROADMAP.md` — только для определения текущего этапа

## Источник истины

`baseline/topking/HamsterKingMobile.current.user.js` — каноническая рабочая версия.

Все изменения делаются минимальным патчем поверх этого файла.

Если текст задачи противоречит фактической реализации baseline, нельзя переписывать механику по тексту. Сначала сравнить baseline, старый подтверждённый рабочий исходник и реальные API/definitions игры.

## Приоритет источников

1. Канонический baseline.
2. Проверенный старый рабочий скрипт/сохранённый исходник.
3. Реальные API и definitions игры.
4. Roadmap и конкретное техническое задание.
5. Контекст и память чата.

## Перед изменением

- прочитать baseline;
- определить точное место изменения;
- проверить, что функция уже не реализована;
- не затрагивать соседние рабочие модули;
- сохранить существующую механику, если пользователь прямо не просил её изменить.

## После изменения

- syntax check;
- проверка конкретного изменённого runtime-path;
- backup live;
- deploy;
- public delivery check;
- live verification;
- только после подтверждения пользователя обновлять canonical baseline.

## Команда для старта нового чата

> Работай по `docs/HK_NEW_CHAT_START.md`. Сначала прочитай canonical baseline в `baseline/topking/`. Не восстанавливай и не переосмысливай существующую механику по тексту. Все изменения делай только поверх точного текущего baseline. Затем выполняй указанный мной этап из `docs/HK_MASTER_ROADMAP.md`.
