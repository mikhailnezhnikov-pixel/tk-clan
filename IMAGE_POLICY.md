# Top King — правила работы с игровыми изображениями

## Главный принцип
На сайте нельзя использовать выдуманные, сгенерированные, стоковые или случайно найденные изображения вместо оригинальных изображений Hamster King.

## Источники по приоритету
1. `assets/` — уже одобренная библиотека изображений сайта.
2. Изображение, которое пользователь прислал в чат и явно одобрил для сайта.
3. Публичный официальный источник Hamster King — только как кандидат на согласование.

## Что запрещено
- Генерировать картинку для замены игрового изображения.
- Использовать стоковые иллюстрации или изображения из сторонних игр.
- Подставлять первое похожее изображение из поиска.
- Подменять неизвестную картинку эмодзи/иконкой без явной просьбы.
- Добавлять новую внешнюю картинку на сайт без подтверждения пользователя.

## Режим кандидата
Если нужного изображения нет в `assets/image-manifest.json`, сначала показать пользователю предложение в таком формате:

> Нашёл кандидата: **[что изображено]**  
> Хочу использовать в блоке: **[раздел / карточка / заголовок]**  
> Источник: **[официальный источник или пользовательский файл]**  
> Сопоставление: **[почему считаю, что это нужный игровой объект]**  
> Действие: **Поставить / Не ставить / Показать другой вариант**

До ответа `Поставить` сайт не менять.

## После подтверждения
После подтверждения:
1. Сохранить изображение в подходящую папку `assets/...`.
2. Добавить запись в `assets/image-manifest.json`.
3. Использовать локальный путь из manifest, а не внешний hotlink.
4. Повторно не спрашивать подтверждение для той же записи, пока пользователь не попросит заменить изображение.

## Поведение при неопределённости
Если уверенность в сопоставлении недостаточна, не угадывать. Показать 1–3 кандидата и кратко объяснить различия.

## Правило для будущих правок сайта
При любой задаче, где появляется новая иллюстрация, сначала проверить `assets/image-manifest.json`. Если подходящая одобренная запись существует — использовать её. Если нет — перейти в режим кандидата и не вносить визуальную замену до подтверждения.
